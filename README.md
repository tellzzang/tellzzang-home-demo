# Tellzzang Studio — Notion ➔ GitHub Pages Demo

노션 개인 샘플 페이지([탤짱의 디지털 홈 | Tellzzang Studio (샘플)](https://app.notion.com/p/41b973637abb810aa1b2c44e9bddc621))의 구조와 콘텐츠를 **Super.so 스타일의 다중 테마 홈페이지**로 변환해 GitHub Pages에 배포한 데모 프로젝트입니다.

## 주요 기능
- **실시간 3종 스타일 전환**: `드라마틱 스튜디오` / `Super.so 미니멀` / `웜 매거진`
- **노션 블록 ➔ 웹 UI 매핑**: Callout, Columns(Bento Grid), Headings(Project Showcase Modal), Table(필터·검색 아카이브), Checklist(실시간 진행률 트래커)
- **원본 마크다운 비교 뷰어**: 상단 `</> 노션 원본 보기` 클릭 시 `notion-source.md`와 변환 매핑 확인
- **`tellzzang.com` 서브도메인 호환**: 추후 `CNAME` 파일 1줄만 추가하면 기존 티스토리 블로그를 건드리지 않고 커스텀 서브도메인으로 연결 가능
