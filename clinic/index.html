3D INTERACTIVE FLASHCARDS

🃏 빈출 킬러 개념 4선 (터치해 뒤집기)

모바일에서도 카드 아무 곳이나 터치하면 3D 회전과 함께 핵심 함정이 펼쳐집니다.

CONCEPT 01 · 클릭해 정답 확인

명목 GDP vs 실질 GDP

기준연도와 비교연도에서 항상 같아지는 것은?

KEY POINT

기준연도에서는 당해연도 가격과 기준연도 가격이 같으므로 명목 GDP = 실질 GDP이며, GDP 디플레이터는 항상 100이 됩니다!

다시 터치하면 앞면으로
CONCEPT 02 · 클릭해 정답 확인

고용지표 표 해석 함정

실업률이 같은데 실업자 수도 같을까?

KEY POINT

아니요! 두 해의 15세 이상 인구나 경제활동참가율이 다르면, 실업률(%)이 같더라도 실제 실업자 수(명)는 완전히 달라질 수 있습니다.

다시 터치하면 앞면으로
CONCEPT 03 · 클릭해 정답 확인

기회비용과 매몰비용

이미 지불해 환불 안 되는 돈은 포함할까?

KEY POINT

회수 불가능한 매몰비용은 합리적 선택 시 절대 고려하지 않습니다! 기회비용은 명시적 비용 + 암묵적 비용만 합산하세요.

다시 터치하면 앞면으로
CONCEPT 04 · 클릭해 정답 확인

원/달러 환율 상승

원화 가치는 어떻게 변할까?

KEY POINT

원/달러 환율 상승 = 달러 가치 상승, 원화 가치 하락(평가절하)! 수출품 가격 경쟁력은 높아지지만 수입 원자재 물가와 외채 상환 부담은 커집니다.
